# easy-Tenancy-V4

A tenancy management app with AI integration using Genspark.ai.

## Setup

1. Install dependencies: `npm install`
2. Set your Genspark.ai API key in `.env` file as `GROK_API_KEY`
3. Run the app: `npm start`

## Connecting to Genspark.ai

The app connects to Genspark.ai API for AI-powered features. The current implementation assumes a Claude-like API, but may need adjustment based on Genspark.ai's actual API specification.

If the connection fails, please provide the correct API endpoint, authentication method, and model name.
